# 🍼 คลังนมแม่

เว็บแอพสำหรับแม่ ๆ บันทึกการปั๊มนมและสต็อกนมแม่ ใช้ร่วมกันทั้งครอบครัว (แม่ พ่อ ยาย พี่เลี้ยง)
บอกยอดคงเหลือ วันหมดอายุของแต่ละถุง และถุงไหนควรใช้ก่อน — แต่ละครอบครัวเห็นเฉพาะข้อมูลของตัวเอง

## ทำอะไรได้

- ล็อกอินด้วย LINE (มีอีเมลเป็นทางสำรอง)
- สร้าง "สมุดนม" ของลูก แล้วชวนคนในบ้านเข้ามาด้วยลิงก์เชิญ (ส่งทาง LINE ได้)
- บันทึกปั๊มนมเป็นออนซ์หรือ ml แบ่งหลายถุง เลือกที่เก็บ (ตู้เย็น/ช่องแช่แข็ง/อุณหภูมิห้อง/กระติก/ป้อนทันที)
- หน้าสต็อก: ยอดรวม พอป้อนได้กี่วัน ถุงที่ควรใช้ต่อไป เตือนถุงที่เกินระยะเก็บ
- ประวัติ: กราฟปริมาณที่ปั๊มได้ 14 วัน + บันทึกรายวัน 30 วัน
- ทุกคนในบ้านเห็นข้อมูลอัปเดตทันที (Supabase Realtime)
- แพ็กเกจ: ทดลองฟรี 30 วัน → พรีเมียม (เชิญคนเพิ่ม + ส่งออก CSV) · บันทึกเองได้ตลอดแม้แพ็กเกจหมด
- PDPA: หน้านโยบายความเป็นส่วนตัว ขอความยินยอมตอนเริ่มใช้ ลบบัญชีเองได้
- เพิ่มไปหน้าจอหลักได้เหมือนแอพ (PWA) · โหมดมืดสำหรับปั๊มนมตอนกลางคืน

## เทคโนโลยี

- Next.js 16 (App Router, Server Actions, `proxy.ts`) + TypeScript + Tailwind v4
- Supabase (Postgres + Auth + Realtime + RLS)
- Deploy: Vercel (ภูมิภาค sin1)

## โครงสร้าง

```
src/
  app/
    (app)/            หน้าที่ต้องล็อกอิน: สต็อก (/), ประวัติ, ตั้งค่า
    auth/line/        ล็อกอิน LINE → สร้างผู้ใช้ใน Supabase
    auth/callback/    ลิงก์ล็อกอินจากอีเมล
    login/ welcome/ join/[code]/ privacy/
  components/         milk-provider (ข้อมูล + realtime), stock-view, history-view, sheets
  lib/milk.ts         ตรรกะถุงนม: วันหมดอายุ หน่วย oz/ml วันเวลา
supabase/
  migrations/0001_init.sql   ตาราง + สิทธิ์ (RLS) + ฟังก์ชัน
  tests/                      ชุดทดสอบว่าครอบครัวแยกข้อมูลกันจริง (45 ข้อ)
```

## เริ่มใช้งาน

ทำตาม [`supabase/README.md`](supabase/README.md) ทีละขั้น: Supabase → LINE Developers → Vercel

```bash
npm install
cp .env.local.example .env.local   # ใส่ค่า
npm run dev                         # http://localhost:3000
npm run build && npm run lint
npm run test:db                     # ต้องมี Postgres ในเครื่อง (ดู supabase/tests/run.sh)
```

## สิ่งที่ยังไม่ทำ (เฟสถัดไป)

- แจ้งเตือนทาง LINE OA (ถุงใกล้หมดอายุ / ถึงเวลาปั๊ม)
- รับชำระเงิน PromptPay ในแอพ + หน้าผู้ดูแลระบบ (ตอนนี้ต่ออายุด้วย SQL ดู `supabase/README.md`)
- บันทึกตอนไม่มีอินเทอร์เน็ต
